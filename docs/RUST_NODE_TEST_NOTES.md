# Rust Node Test Notes

This document provides summary documentation and test coverage notes for the nodes added to MiniHou's Rust core engine (`minihou-core`): `grow`, `select_path`, `select_loop`, `select_ring`, `mirror`, `convex_decomposition`, `rbd_material_fracture`, `image_file`, `uv_flatten`, `glue_cluster`, `occlusion`, `lsystem`, `voronoi_fracture_points`, and `attrib_paint`.

## Selection Nodes

### `grow`
The `grow` node proceduralizes Blender's Select More / Select Less operators across point, edge, and primitive domains by expanding or contracting selection masks over mesh topology, leaving input geometry and point coordinates untouched while writing group attributes. Critical parameters include `domain` (`points`, `edges`, `primitives`), `mode` (`grow` or `shrink`), `steps` (0..100,000), `face_step` (stepping across polygons sharing a point vs. sharing an edge), `keep_selection`, `result_group_name`, `output_group`, and `output_group_name`. Known limits: does not mutate geometry, UVs, or normals; steps outside 0..100,000 or negative return an error; shrinking stops at open mesh boundaries without eroding them. Test coverage: `grow_quad_grid_by_vertex_and_edge_with_delta_group` (grid face-step growth and delta groups), `shrink_is_select_less_with_removed_delta` (shrink core and removed delta), `grow_cube_open_boundary_and_full_selection` (cube manifold growth and open boundary preservation), `grow_empty_zero_steps_isolated_and_nonmanifold` (zero steps, non-manifold fin, isolated vertices), `grow_points_and_edges_domains` (points and edges domain selection), `test_selection_nodes_empty_and_single_element` (0-element and 1-element geometries across domains), `test_selection_nodes_degenerate_and_nonmanifold` (zero-area faces and duplicate vertices), `test_selection_nodes_nan_inf_and_huge_params` (NaN positions handling and >100,000 steps rejection), `test_selection_nodes_missing_groups_and_invalid_enums` (clean errors on missing groups and invalid domain/mode enums), `test_selection_nodes_determinism_and_attribute_preservation` (deterministic group generation and preservation of Cd, N, UV, material_index), and `test_selection_nodes_topology_euler_unchanged` (Euler characteristic and topology invariance on cube and grid).

### `select_path`
The `select_path` node determines topological shortest paths between elements across point, edge, or primitive domains using Dijkstra graph search (`shortest_distance`), breadth-first hop counts (`fewest_steps`), or directional angle heuristics (`most_direct`). Key parameters include `domain` (`points`, `edges`, `primitives`), `start` and `end` indices, `waypoints` (whitespace/comma-separated element IDs or edge point pairs), `method`, `closed` (routing from final waypoint back to start), `group_name`, and `combine` (`replace` or `union`). Known limits: requires a topologically connected route between endpoints (returns a clear error if elements are in disjoint components); invalid or out-of-bounds element indices return explicit errors; negative start/end indices are rejected. Test coverage: `path_methods_differ_on_a_weighted_shortcut` (Dijkstra metric distance vs. topological hop count), `path_waypoints_closed_union_and_errors` (multi-waypoint loops, primitive/edge paths, union combination, out-of-range errors), `test_selection_nodes_empty_and_single_element` (clear errors on empty geometry and self-loop paths on single points), `test_selection_nodes_nan_inf_and_huge_params` (non-panicking, safe handling of NaN/Inf vertex coordinates), `test_selection_nodes_missing_groups_and_invalid_enums` (invalid enum validation), `test_selection_nodes_determinism_and_attribute_preservation` (deterministic path selection and attribute passthrough), and `test_selection_nodes_topology_euler_unchanged` (Euler characteristic and topology preservation).

### `select_loop`
The `select_loop` node traces continuous edge loops straight through valence-4 grid vertices, follows n-gon cap perimeters, or follows single-polygon open mesh borders from specified seed edges. Key parameters include `seeds` (edge identifiers, point pairs, or edge groups), `domain` (`edges`, `points`, `primitives`), `mode` (`edge_loop` or `boundary_loop`), `direction` (`both`, `forward`, `backward`), `group_name`, and `combine` (`replace` or `union`). Known limits: `edge_loop` halts at poles (vertices with valence != 4), borders, and non-manifold edges; `boundary_loop` follows boundary edges and halts where borders branch; empty seed strings safely produce an empty group without error. Test coverage: `loops_rings_and_boundaries` (interior row traversal, directional walks, boundary loops vs. interior seeds), `cube_loop_stops_at_poles_ring_closes_and_ngons_stop_rings` (cube valence-3 corners halt edge loops, closed tube loop wrap-around), `test_selection_nodes_empty_and_single_element` (empty mesh safety), `test_selection_nodes_missing_groups_and_invalid_enums` (invalid mode/combine enums), `test_selection_nodes_determinism_and_attribute_preservation` (deterministic edge loop extraction and attribute preservation), and `test_selection_nodes_topology_euler_unchanged` (invariance of mesh topology and Euler characteristic).

### `select_ring`
The `select_ring` node steps across opposite edges of quad strips (or selects face strips when domain is set to `primitives`) starting from specified seed edges. Key parameters include `seeds`, `domain` (`edges`, `points`, `primitives`), `direction` (`both`, `forward`, `backward`), `group_name`, and `combine` (`replace` or `union`). Known limits: ring walks terminate at non-quad faces (triangles or n-gons), open boundary edges, and non-manifold edges; empty seeds write an empty group safely. Test coverage: `loops_rings_and_boundaries` (edge ring and face loop extraction across quad grids), `cube_loop_stops_at_poles_ring_closes_and_ngons_stop_rings` (closed 4-edge cube ring, pentagon strip termination), `test_selection_nodes_empty_and_single_element` (empty geometry handling), `test_selection_nodes_missing_groups_and_invalid_enums` (invalid direction enum rejection), `test_selection_nodes_determinism_and_attribute_preservation` (deterministic output and attribute preservation), and `test_selection_nodes_topology_euler_unchanged` (mesh topology and Euler characteristic invariance).

## Modeling & Transforms

### `mirror`
The `mirror` SOP reflects geometry across an arbitrary 3D plane, providing plane offsetting, normal reversal, optional bisecting (`cut`), and seam vertex consolidation (`consolidate_seam`). Key parameters include `origin`, `normal`, `offset`, `reverse`, `cut`, `keep_original`, `consolidate_seam`, `distance` (seam welding tolerance), `unshared_only` (restricting consolidation to open boundary seam edges), and `operation` (`mirror_all` or `mirror_selected` with `group`). Known limits: vector attributes (`N`, `v`, `up`, `accel`, `force`, `tangentu`, `tangentv`) are reflected across the plane while scalar, color, UV, and primitive attributes are preserved; degenerate normal vectors `[0,0,0]` safely default to `[1,0,0]`; bug found: point-only geometries (point clouds without primitives) are stripped of all points when `keep_original: true` due to `compact` dropping unreferenced vertices (marked as `#[ignore = 'BUG: ...']`). Test coverage: `mirror_defaults_weld_the_seam_and_flip_winding` (seam welding and polygon winding inversion for positive normals), `mirror_attributes_reflect_vectors_only` (reflection of vector attributes vs. preservation of colors and UVs), `mirror_reverse_and_cut_keep_the_chosen_side` (plane bisecting cut and direction reversal), `mirror_offset_moves_the_plane_along_direction` (plane offset translation), `mirror_unshared_only_skips_interior_points` (unshared boundary edge welding), `mirror_selected_and_output_group` (mirror_selected operation and group output), `mirror_plane_helper` (plane math), `test_mirror_empty_and_single_element` (empty mesh and single triangle mirroring with seam welding), `test_mirror_points_only_preserves_points` (ignored bug test on point cloud compacting), `test_mirror_degenerate_and_nan_inf` (zero-area triangles and zero-normal fallback), `test_mirror_missing_groups_and_invalid_enums` (error handling on unknown groups and invalid operations), `test_mirror_determinism_and_attribute_preservation` (determinism and attribute stability), and `test_mirror_topology_euler_manifold` (manifold topology and Euler characteristic on mirrored cubes).

## UV & Image Nodes

### `uv_flatten`
The `uv_flatten` node computes 2D UV texture coordinates for 3D polygon meshes using Least Squares Conformal Mapping (LSCM) combined with angle-based seam detection and island rectangle packing into the `[0, 1]` UV coordinate space. Key parameters include `seam_angle` (dihedral threshold angle in degrees), `split_attrib` (primitive attribute for manual island partitioning), `padding` (border margin between UV islands), and `island_attrib` (primitive attribute name for island IDs). Known limits: operates exclusively on closed polygon meshes; open curves or polylines return a clean error (`uv_flatten works on polygons, but the input has open curves`); empty meshes pass through cleanly; pre-existing point or primitive UV attributes are replaced with packed vertex UVs. Test coverage: `test_uv_flatten_matches_python_parity` (full golden comparison matching Python parity oracle), `test_uv_flatten_grid_developable` (quad grid developable flattening and island assignment), `test_uv_flatten_errors` (open curve rejection and nonexistent split attribute error), and `test_uv_flatten_edge_cases` (empty geometry passthrough, single triangle flattening into unit square, degenerate collinear triangle handling, determinism, and attribute preservation of Cd and material_index).

### `image_file`
The `image_file` node reads 8-bit, 16-bit, and 32-bit float PNG images from disk to construct a planar 2D quadrilateral mesh or heightfield displaced by image pixel luminance or color channels. Key parameters include `file` (PNG file path), `max_size` (maximum dimension for automatic downsampling), `colorspace` (`auto` sRGB-to-linear conversion, or `stored`), `size` (width in units), `center` (3D center offset), `height` (`none`, `luminance`, `red`, `green`, `blue`, `alpha`), and `height_scale`. Known limits: requires an existing PNG file with at least 2x2 pixels; dimensions exceeding 16,000,000 pixels return an error; downsampling uses box averaging. Test coverage: `test_image_file_validations` (empty file and missing file checks), `test_image_file_golden_comparison` (8-bit and 16-bit golden comparisons), `test_image_file_graph_cook_8bit` (graph evaluation, attribute generation for Cd, Alpha, uv, height), `test_image_file_graph_cook_16bit` (16-bit stored colorspace loading), `test_image_file_session_caching_and_recook` (session file mtime cache invalidation), `test_image_file_downsample_and_errors` (max_size downsampling limits), and `test_image_file_edge_cases_and_determinism` (invalid colorspace and height enums, huge max_size safety, and cooking determinism).

## Simulation & Fracture Nodes

### `glue_cluster`
The `glue_cluster` node constructs RBD glue constraint networks and hierarchical cluster assignments between fractured pieces based on adjacent face contact surface areas. Key parameters include `piece_attrib` (scalar integer primitive attribute; empty string uses mesh connectivity), `output` (`pieces` with cluster attributes or `constraints` line geometry), `strength` (tensile/shear bond limit), `strength_variation` (0..1 random noise factor), `seed`, `max_gap` (proximity threshold for contact detection), `min_area`, `min_share`, `clusters` (target cluster count; 0 disables clustering), and `weak` (fractional strength multiplier for inter-cluster bonds). Known limits: input geometry must consist of closed polygons (open curves return a clean error); empty input geometry safely returns empty geometry in pieces mode or empty constraint networks; non-existent or non-integer piece attributes return clear errors. Test coverage: `test_glue_cluster_filters` (min_area dropping links, min_share thresholding), `test_glue_cluster_invalid_attrib_error` (missing piece attribute detection), `test_glue_cluster_open_curves_error` (open curve rejection), `test_glue_cluster_seeded_variation_and_zero_strength` (strength variation distribution and zero-strength handling), `test_glue_cluster_golden_parity` (full golden comparison with Python oracle), `test_glue_cluster_empty_and_single_element` (empty mesh safety in pieces and constraints modes, single-piece triangle clustering), and `test_glue_cluster_invalid_params_and_determinism` (invalid output enum rejection, negative strength handling, and seeded random determinism).

### `convex_decomposition`
The `convex_decomposition` node segments complex closed polygon solids into near-convex volumetric parts using pure-Rust planar clipping and capping heuristics without external native dependencies. Key parameters include `max_concavity` (0.0..1.0 concave deficit tolerance), `max_pieces` (1..1000 partition limit), `min_volume` (0.0..0.5 minimum sub-piece volume fraction), `search` (1..200 candidate plane evaluations), `piece_attrib` (primitive attribute name for piece IDs), and output groups (`inside`, `outside`, `cutpoints`, `cutedges`). Known limits: requires a watertight closed mesh with positive signed volume; open meshes, negative-volume inverted meshes, and non-manifold geometries fail with explicit errors; empty geometry passes through untouched. Test coverage: `convex_box_matches_python_golden` (box decomposition golden parity), `l_prism_is_split_into_closed_pieces` (L-prism decomposition into closed pieces with volume preservation), `test_convex_decomposition_empty_and_errors` (empty geometry passthrough, open mesh rejection, invalid parameter bounds), and `test_convex_decomposition_determinism_and_attribute_preservation` (deterministic piece assignment and preservation of Cd and material_index).

### `rbd_material_fracture`
The `rbd_material_fracture` node is a high-level composite fracture SOP that orchestrates Voronoi point scattering, Voronoi cutting, piece assembly, glue constraint generation, and optional convex decomposition with material presets. Key parameters include `material` (`concrete`, `brick`, `stone`, `wood`, `glass`, `ceramic`, `ice`, `metal`, `custom`), `density`, `friction`, `restitution`, `glue_strength`, `pieces` (>=2 initial Voronoi pieces), `fracture_level` (1..4 recursive fracture hierarchy), `sub_pieces` (>=2 sub-fracture count), `seed`, `surface_fraction`, `gap`, `convex_parts`, `glue`, `clusters`, and `output` (`pieces` or `constraints`). Known limits: total recursive piece count `pieces * sub_pieces^(level-1)` cannot exceed 2000; input must be a watertight closed solid for interior Voronoi scattering; output `constraints` requires `glue` to be enabled; empty input geometry fails cleanly. Test coverage: `python_two_piece_box_golden` (parity comparison against Python oracle for mass, piece IDs, and inside groups), `test_rbd_material_fracture_limits_and_errors` (rejection of empty geometry, pieces < 2, sub_pieces < 2, level > 4, total pieces > 2000, invalid material enums, constraints without glue), and `test_rbd_material_fracture_constraints_mode_and_determinism` (constraints mode generation and determinism of masses and piece IDs under fixed seed).

### `voronoi_fracture_points`
The `voronoi_fracture_points` node scatters seed points within the interior volume, along the surface, or concentrated around collision impact locations of 3D geometry for use with Voronoi fracture nodes. Key parameters include `count` (number of points), `seed`, `surface_fraction` (0..1 fraction allocated to surface points), `cluster_amount`, `clusters`, `cluster_radius`, `min_distance` (minimum point clearance), `relax` (Lloyd relaxation iterations), `source` (`scatter` or `impacts`), `impact_radius`, `impact_share`, `merge_clusters`, and `piece_attrib`. Known limits: interior volume scattering (`surface_fraction < 1.0`) requires a watertight closed manifold mesh (every edge shared by 2 polygons); open meshes are permitted only when `surface_fraction = 1.0`; `source = "impacts"` requires non-empty point geometry on the second input; empty geometry returns an error. Test coverage: `python_box_seeded_golden` (parity check with Python seeded point output), `python_surface_point_order` (surface sampling order verification), `test_voronoi_points_empty_and_single_element` (empty geometry error, count: 0 safe handling, open single triangle surface scattering), `test_voronoi_points_errors_and_limits` (invalid source enum, impacts mode without second input, open mesh interior scatter error), and `test_voronoi_points_determinism_and_clusters` (seeded determinism, piece attribute generation, and K-means cluster merging).

## Procedural & Ray Nodes

### `occlusion`
The `occlusion` node calculates per-point ambient occlusion (AO) or geometric thickness by tracing hemisphere cosine-weighted rays against a BVH ray-tracing mesh. Key parameters include `mode` (`ambient_occlusion`, `thickness`), `name` (output attribute name, defaults to `ao` or `thickness`), `rays` (ray count per point, >=1), `spread` (1..90 degrees cone angle), `max_distance`, `bias`, `seed`, `self_occlusion` (cast rays against own mesh), `normalize`, `invert`, `blur` (topological neighbor smoothing passes), and `group` (point selection filter). Known limits: requires a polygon mesh input with primitives (empty meshes error); when `self_occlusion: false`, a second `occluders` input geometry must be connected; total rays (`selected_points * rays`) cannot exceed the 20,000,000 ray safety cap; rays must be positive. Test coverage: `python_roof_golden` (golden roof-over-plate AO and thickness parity), `test_occlusion_empty_and_single_element` (empty input rejection, single triangle self-occlusion), `test_occlusion_degenerate_and_params` (zero-area triangle safe evaluation, rays <= 0 error, invalid mode/name enums, missing occluder input when self_occlusion is false), and `test_occlusion_determinism_and_attribute_preservation` (seeded ray determinism and preservation of Cd, UV, and material_index attributes).

### `lsystem`
The `lsystem` node creates 3D procedural branching skeletons and fractal curves by expanding string rewrite grammars and executing 3D turtle graphics commands. Key parameters include `premise` (initial axiom string), `rules` (semicolon-separated rewrite rules), `generations` (0.0..12.0 recursion depth), `step_size` / `step`, `step_size_scale`, `angle`, `angle_scale`, `yaw`, `pitch`, `roll`, `thickness` / `width`, `thickness_scale`, `seed` / `random_seed`, `random_scale`, `point_attributes` (writes `segs`, `div`, `lage`, `arc`, `up`, `gen`), and `group_prefix`. Known limits: only skeleton curves are supported (geometry types `tube` and leaf stamping on inputs 0..2 return explicit unsupported errors); rules cannot use stochastic weights (`:`), contextual matching (`<`, `>`), or parametric equations (`()`); symbol expansions exceeding 2,000,000 abort for safety; unmatched brackets `[` or `]` fail with clear errors. Test coverage: `python_branch_golden` (turtle geometry coordinate and attribute parity against Python), `unsupported_parametric_rule_is_explicit` (parametric rule rejection), `python_default_counts` (default rule expansion symbol/point counts), `test_lsystem_empty_and_single_element` (empty premise safety, single 'F' step curve), `test_lsystem_errors_and_unsupported` (generations bounds, tube type rejection, leaf input rejection, unmatched brackets, bad rule syntax), and `test_lsystem_determinism_and_attributes` (seeded random scale determinism and point attribute verification).

### `attrib_paint`
The `attrib_paint` node applies interactive or procedural brush edits to geometry attributes across `point`, `prim`, or `edge` domains using the compressed `mhp1:` base64 zlib wire format. Key parameters include `attribute` (target attribute name), `domain` (`point`, `prim`, `edge`), `kind` (`float`, `int`, `vec3`), `default` (scalar fallback value), `default_vec` (3-component vector fallback), and `data` (encoded `mhp1:` payload string). Known limits: attribute name `"P"` is reserved and rejected; edge domain cannot accept `vec3` (only scalar float or integer edge groups); out-of-bounds element indices from modified topologies are safely ignored as stale edits and logged in detail attribute `paint_stale_<name>`; NaN/Inf values in encoded payloads or merge edits error cleanly. Test coverage: `attrib_paint_python_golden_codec_and_merge` (mhp1 base64/zlib decode, encode, and merge parity), `attrib_paint_domains_types_defaults_and_stale` (point float, prim vec3, edge int, default fallbacks, and stale index counting), `test_attrib_paint_empty_and_single_element` (empty geometry handling across point, prim, edge domains, single point and single triangle painting), `test_attrib_paint_degenerate_and_nan_inf` (zero-area triangles, rejection of NaN/Inf during encode and merge), `test_attrib_paint_missing_and_invalid_enums_and_names` (rejection of "P", leading digits, spaces, invalid domain/kind enums, edge vec3 error), and `test_attrib_paint_determinism_and_attribute_preservation` (deterministic evaluation and preservation of existing attributes).
