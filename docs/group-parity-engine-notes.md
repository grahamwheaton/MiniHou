# Group parity engine scope

The extended group nodes follow the [SideFX geometry node index](https://www.sidefx.com/docs/houdini/nodes/sop/index.html) and the individual documentation for [Group Copy](https://www.sidefx.com/docs/houdini/nodes/sop/groupcopy.html), [Group Transfer](https://www.sidefx.com/docs/houdini/nodes/sop/grouptransfer.html), [Group Find Path](https://www.sidefx.com/docs/houdini/nodes/sop/groupfindpath.html), [Group from Attribute Boundary](https://www.sidefx.com/docs/houdini/nodes/sop/groupfromattribboundary.html), and [Groups from Name](https://www.sidefx.com/docs/houdini/nodes/sop/groupsfromname.html). These are useful mesh subsets, rather than replacements for every Houdini option.

| Node | Supported behavior | Current limit |
| --- | --- | --- |
| Group Copy | Point, primitive, edge and vertex group patterns; optional prefixes; index mapping; scalar integer point/primitive/vertex attribute matching; skip, overwrite and suffix conflicts; optional empty groups. | Geometry attributes cannot hold string values, so string attribute matching is unavailable. Edge matching uses derived edge index. |
| Group Transfer | Point, primitive and edge group patterns, prefixes, conflicts, distance threshold and empty groups. | Uses exact nearest representative positions: point position, primitive centroid and edge midpoint. This can differ from Houdini's closest-surface mapping. Ordered group order is not stored. |
| Group Find Path | Point and edge paths through listed elements or start/end pairs; shortest distance along topology; same-domain collision group. Numeric base tokens preserve their order; named groups use element-number order. | No loop/ring extension, turn-minimizing preference, UV restriction or cross-domain collision. Disconnected paths raise an error. |
| Group from Attribute Boundary | Primitive, point and vertex attribute discontinuities with numeric tolerance; base group perimeter; open polygon and optional curve edges; edge, point, primitive and vertex output. Shared edges with three or more incident faces compare every pair. | No degenerate bridge removal. Output projection follows MiniHou incidence rules. |
| Groups from Name | One group per nonempty string in a detail name table; prefixes; replace/union; invalid names ignored or converted to valid names. Name collisions after conversion union their members. | MiniHou represents each element's name as an integer attribute indexed into `detail["<attribute>_names"]`, because the geometry attribute tables permit only numeric and boolean arrays. Houdini's `xn__` encoding is unavailable. |

[Group Range](https://www.sidefx.com/docs/houdini/nodes/sop/grouprange.html) implements inclusive element-number Start/End, relative Start/End, Start and Length, equal partitions, a base group, the alternating filter, and optional independent processing of disconnected regions. Connectivity attribute partitioning is not exposed. The extended [Group Expand](https://www.sidefx.com/docs/houdini/nodes/sop/groupexpand.html) supports point, primitive, edge and vertex rings, contraction, signed steps and flood fill. Normal, connectivity-attribute and collision constraints remain outside the exposed schema.
