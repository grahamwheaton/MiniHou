## Inputs and outputs that differ

* `bezier` (Curve 2.0 geometry node): inputs: Houdini has **Input Curves**; **If the input contains goemetry you don’t want to edit, you just want to add curves**; **The input contains some curves you want to make editable, and other geometry you just want to pass through** - MiniHou has `geo`
* `boolean_fracture` (Boolean Fracture geometry node): outputs: Houdini has **Fractured Geometry**; **Constraint Geometry** - MiniHou has `geo` **Note:** Same: constraint geometry comes from glue_cluster, not from a second output.
* `curve` (Curve 2.0 geometry node): inputs: Houdini has **Input Curves**; **If the input contains goemetry you don’t want to edit, you just want to add curves**; **The input contains some curves you want to make editable, and other geometry you just want to pass through** - MiniHou has `geo`
* `lattice_grid` (Lattice Deform geometry node): inputs: Houdini has **Data Source**; **Initial Source**; **Deformed Source** - MiniHou has none **Note:** MiniHou's lattice is the lattice_grid/lattice pair (rest, deformed), not Houdini's one node with three sources.
* `points_to_surface` (Particle Fluid Surface 2.0 geometry node): inputs: Houdini has **Particles and Volumes**; **Collision Objects and Volumes**; **Mask Volumes** - MiniHou has `points` **Note:** Collision and mask volumes are not supported.
* `polyreduce` (PolyReduce 2.0 geometry node): inputs: Houdini has **Geometry to reduce**; **Rest geometry**; **View geometry**; **Curves**; **Closed surface** - MiniHou has `geo` **Note:** Rest, view, curve and closed-surface inputs (constraints on what may collapse) are not supported; keep_borders covers the common case.
* `polysplit` (PolySplit 2.0 geometry node): inputs: Houdini has **Input Geometry**; **Projection Curve** - MiniHou has `geo` **Note:** The projection curve (split along a curve drawn on the surface) is not supported; loops/position split by edge loop.
