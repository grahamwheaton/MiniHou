# Higgsas Geo Nodes against MiniHou

267 asset node groups from the library (Blender 5.0 file), each compared with MiniHou's nodes. Generated by `tools/higgsas_triage.py` from `tools/higgsas_verdicts.txt`; the verdicts are hand-made, from each group's sockets, size and the Blender nodes inside it. Built from this list so far: `solidify`, `falloff`, `occlusion`, `contour`, `slice`, `sdf_shape`, `uv_transform`, `curve_simplify` (marked "have it" with a note "built: ...").

## What the library mostly is

Most groups are Blender *fields*: they take a position or an index and give a value (falloffs, selections, noise, linear algebra), and they chain 2-3 thousand Math nodes between them. MiniHou has no field graph; the same job is a point attribute, a group, or a wrangle expression. So those become one native node that writes an attribute (`falloff`), or a wrangle function (`curlnoise`, `ease`, `gauss`), not 30 nodes.
