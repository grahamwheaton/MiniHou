# Stream gestures and Dynamic Nodes

Alt-drag one connected node and release to detach it while forwarding its upstream source to every downstream consumer. The node remains loose at its new position. A horizontal shake (three reversals of at least 18 screen pixels, within 650ms between turns) performs the same operation on release. Escape, pointer cancellation or focus loss cancels before committing. Move and rewire are one undo entry.

Exactly one incoming connection is required when a node has consumers. Fan-out is safe: every downstream occurrence is replaced, preserving other wires and multi-input order. Multiple upstream occurrences, even from the same source, are ambiguous and rejected without any edit. Source nodes with consumers cannot be detached this way. Multi-selected nodes only move; their wires remain. Display/export flags are unchanged; a displayed detached node may therefore show missing-input feedback until reconnected.

Drag a completely loose node by its body/title so the pointer approaches a noodle. A gold highlight and status message identify insertion. Release inserts it into that exact wire. The node needs exactly one compatible input candidate, no other mandatory unconnected inputs, and a compatible output. Incompatible nodes do not highlight. Near-overlapping ambiguous noodles do not highlight; zoom in or wire manually. Hover scanning is capped at 1,000 visible wires. The server revalidates the exact edge on release; concurrent changes reject the entire move/insertion batch. Escape cancels; Undo restores wires and positions together.

Dynamic Nodes is ON by default, with an immediate switch in the node pane header and Preferences. Nearby unselected nodes gently repel around a drag, then spring back to their saved positions. These are visual offsets, not automatic layout changes. Nodes and noodles move together. Offsets are bounded to 12 graph pixels, affect at most 48 neighbours, respect reduced motion, and are disabled above 500 nodes. The browser stores the preference; no graph metadata is added. There is no idle drifting or continuous physics when settled. Turn OFF for a fully stationary graph.

Tests use small fixtures: actual Alt/shake/drop/cancel/Undo browser gestures, persistent option reload, saved-position invariance, and backend multi-input/type/atomicity tests. No massive realised-copy scene is used.
