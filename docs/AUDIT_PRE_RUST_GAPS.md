### Recommendation
1. **Wire immediate P0 UX gaps first (Small effort, high impact):** Connect the native viewport timeline (`VpState.frame`) to `Edit::Time` in [`main.rs`](../rust/crates/minihou-app/src/main.rs), wire viewport `X`/`Delete` and `Alt+N` to append `blast`/`dissolve`/`reverse` nodes, and enable inline node renaming (`F2`/header/context menu) and `Ctrl+F` node search.
2. **Finish Parameter Panel & Modal Modeling parity:** Add color swatches, ramp editors (`float_ramp`/`color_ramp`), file browse (`...`) buttons, group "Select" buttons, and node action buttons in [`params.rs`](../rust/crates/minihou-app/src/ui/params.rs), then upgrade `E` / `I` / `Ctrl+B` / `Alt+E` from immediate node insertion to interactive modal pointer drags.
3. **Add the Geometry Spreadsheet tab:** Upgrade [`geo_info.rs`](../rust/crates/minihou-app/src/ui/geo_info.rs) with a paged egui table backed by the already-ported [`http_geometry::spreadsheet`](../rust/crates/minihou-app/src/http_geometry.rs) logic (supporting domain switching, `@attr` filtering, sorting, and cell editing).
4. **Complete Node Flags & Canvas Organization:** Persist `locked`/`template`/`unload` flags in graph JSON, render `template` nodes as reference wireframes in the 3D viewport, and draw/manipulate `boxes` (frames & sticky notes, already supported in [`http_ops.rs`](../rust/crates/minihou-app/src/http_ops.rs)) on the [`network.rs`](../rust/crates/minihou-app/src/ui/network.rs) canvas.
5. **Port the remaining 10 nodes & 3D Viewport Tools:** Prioritize `uv_flatten`, `voronoi_fracture_points`, `convex_decomposition`, `glue_cluster`, `rbd_material_fracture`, and `attrib_paint` (alongside the 3D Paint brush tool, curve control-point handles, and deformer gizmos).
