# MiniHou Rust port - handoff, 16 Oct 2026

Written when stopping on the home PC. Branch: `native-ui` (https://github.com/grahamwheaton/MiniHou). Everything below was committed and pushed at the end of the session.

## Start here on the other machine

1. Rust 1.99 is pinned by `rust-toolchain.toml` (install rustup if missing).
2. `git fetch origin && git switch native-ui && git pull`
3. Build and run: `cargo build --release --manifest-path rust/Cargo.toml -p minihou-app`, then `rust\target\release\minihou-app.exe`. It starts maximised; the status bar chip shows `Rust core vX . <commit> . <build time UTC>`.
4. Tests: `cargo test --manifest-path rust/Cargo.toml --workspace` (about 600 tests, all green when pushed; two CLI tests launch the app headlessly). Python reference tests: `python -m unittest tests.test_rust_param_meta` etc.
5. After changing node params regenerate metadata: `python tools/dump_rust_param_meta.py`. Rust-only params go in a block in that script, like `lod_bake`, `convex_hull` and `ray`.
6. After changing default key bindings the keymap table in `rust/crates/minihou-app/docs/NATIVE_EDITOR.md` must match (a test compares it; `Command::ALL` is a fixed-size array).

## What exists now (all built and unit-tested; almost none of it seen in the live app)

**Viewport.** Z-up Blender camera; free turntable orbit over the zenith; endless mouse drag (cursor wrap); numpad keys (held-numpad detection on Windows); RMB+WASD fly navigation (pref); box/circle/lasso select as one Select tool with a mode toggle; selection allowed during modal transforms; only the selected object is outlined and the gizmo sits on the active object; Blender-style move/rotate/scale gizmo; snapping defaults to Vertex and is multi-select; Houdini display modes (12 shading modes, MatCap, ghost/hide other objects); points, lines and faces always rendered with a Blender-style Overlays popover (last worker finished, unverified); loop/ring/path selection (Alt, Ctrl+Alt, Ctrl click) and selection promotion on mode switch (`element_select.rs`, spec `docs/RUST_ELEMENT_SELECT.md`); quick tools in the tool strip: Draw (line/polyline/polygon/rectangle/circle), Measure, Knife (K), Loop Cut (Ctrl+R, spec `docs/RUST_LOOP_CUT.md`); view distance is explicit near/far.

**Node editor.** T = tidy (one column per stream, grid snapped); Shift-drag spring physics (header checkbox, snappiness pref); wiggle pulls a node out while the stream keeps flowing; Ctrl+X dissolve; D toggles display; shelf drops land where dropped; insert before the output node with push-down placement; noodle-drag-to-Tab-menu; Shift+RMB-drag slices noodles; box-select noodles; drop-a-node-on-a-noodle insert and pick-up-existing-noodle-end (last worker finished, unverified); Blender-exposed icon; shelf red dot = no Rust version.

**Core nodes.** 160 of 170 Python node types now run on Rust. Still missing: `attrib_paint` (needs base64 + zlib crates), `convex_decomposition`, `glue_cluster`, `image_file`, `lsystem`, `occlusion`, `python` (not portable), `rbd_material_fracture` (needs the three before it), `uv_flatten` (needs LSCM from `minihou/lscm.py`), `voronoi_fracture_points`. `rbd_solver` is a native engine, NOT MuJoCo, so motion will not match Python frame for frame. Per-area docs: `docs/RUST_*.md`.

**USD.** Pure-Rust `openusd` crate: `usd_import`, `usd_export`, File > Export USD (`docs/RUST_USD_STATUS.md`).
**MCP.** Rust HTTP API on 127.0.0.1:8766 so the existing Python MCP server (`tools/setup_mcp.py`) works unchanged (`docs/RUST_MCP_API.md`).
**Blender link.** Rust TCP server on 127.0.0.1:8765; parity work and gaps in `docs/RUST_LINK_STATUS.md`; shared memory not implemented (TCP fallback).
**Blender add-on** (`blender_addon/minihou_link`, version 0.1.6; the app's Blender panel shows "Latest add-on: V..."). Auto-connect; nested modifier layout `Group Input -> MiniHou Plumbing -> Group Output` with migration of old flat groups; disconnect/freeze fixes (bounded network calls). Install with the app's Install add-on button, then restart Blender.
