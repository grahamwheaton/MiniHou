Editor controls

the shelf (under the top bar)one-click tools in Houdini-style tabs (Create, Modify, Model, Polygon, Deform...): click to add after the selected node (or on its own), drag onto the graph to drop it; + picks the tabs, ▴ folds it
Tab / double-click / right-clickadd a node (wired to the selected node)
drag from an output ● to an inputconnect; drop on empty space to add a connected node
drag a connected inputre-route or (drop on empty space) disconnect
click a wire, Deletedisconnect
blue bar on a nodedisplay flag: what Blender shows
Q / B · E · W · R · T (network)Bypass · Template · Selectable Template · Display · Render. Shift-click Template adds references; Ctrl-click Display sets Render. Right-click a node for all flags, Lock and Unload.
X / shake node / Shift-right-dragdelete / disconnect on release / cut wires; Esc cancels gestures
M / L / T / DMute / Lock / Template / Display buttons
drag background / middle mousebox select / pan; Shift adds to selection; wheel zooms
F / Lframe selection (or all) / tidy the layout
3-D view: 1 2 3 4 / Escselect points / edges / faces / whole objects (click or drag a box, Shift adds, Ctrl finds a shortest path, Ctrl+Shift removes; middle mouse orbits) / back to view. The buttons under the view add a node after the one you are looking at (Bevel for edges, Extrude, Inset, Delete, Group for faces...)
timeline (under the 3-D view)▶ plays the graph in real time between the start and end frames (frames are skipped, never queued, if a cook is slower than the frame rate); Space plays or pauses, ← → step, Shift+arrow jumps to the ends, ⟲ loops. Blender's own timeline still drives the frame when it is connected
WASD navigationHold right mouse: look and fly; WASD moves, Q/E down/up, Shift fast, Ctrl slow, wheel speed. Walk / Fly or Shift+backtick toggles; Enter accepts, Escape restores camera. No collision/gravity.
Ctrl+R over 3-D viewLoop cut: hover a quad edge, wheel sets count, click then slide and click to confirm. Escape cancels; right-click during slide centers the cut.
3-D view navigationmiddle mouse orbits, Shift-middle pans, Ctrl-middle dollies, wheel zooms; change navigation and depth orbit in Preferences; the axis gizmo (top right) or Numpad 1 3 7 (Ctrl: opposite side) snap to front / right / top; Numpad 5 perspective or orthographic; F / Numpad . / Home frame the selection or everything
C (pie menu)Houdini's modelling tools in a pie at the pointer, over the graph or the 3-D view: Adjust (top), Deform, Polygons, Group, Create, Build, Edges, Modify, each with a page of tools and a » for more. Hold C, flick towards a slot and let go; or tap C and click (1-8 pick a slot, the middle goes back, Esc closes). A tool adds its node after the one you are looking at, already filled in from the points, edges or faces you selected
moving a selectionwhatever you select (points, edges, faces, objects) shows a Move / Rotate / Scale gizmo at its centre; the first drag adds a transform node after the viewed node (its group is the selected points, its pivot the centre), later drags on the same selection edit that node
handles in the 3-D viewthe node you look at can show arrows to drag; a transform has Move / Rotate / Scale tools (W E R with the pointer over the view and nothing selected): move arrows, one ring per rotation axis (drag around it), scale cubes per axis and a square for uniform scale
layoutdrag the dividers between the graph, the 3-D view and the parameter panel; Graph / Split / 3D set the balance, ⇆ stacks or aligns, ⇄ swaps, ▤ hides the panel; Ctrl+Space over a pane fills the window with it (again to go back). Saved in this browser.
double-click a groupopen the graph inside a group (system) node; the path at the top left of the graph shows where you are (click a name to go back out, Alt+Up goes up one level)
Onetwork box around the selected nodes: drag its title to move it with them, its corner to resize, double-click the title to rename, the dot to change colour
Delete / Ctrl+D / Ctrl+Adelete / duplicate / select all
file name (top left)the graph & library browser: type to search graphs and library nodes (◆), ↑ ↓ Enter open, ⤓ inserts a graph's nodes into this one, ⧉ ✎ 🗑 duplicate / rename / delete, Save As… copies this graph to a new file and switches to it, New graph…
Ctrl+Gsave the selected nodes as a reusable library node and put it where they were (like Houdini's collapse to subnet; Ctrl+Z takes the nodes back). It appears in the Add Node menu under Library; double-click it to edit what is inside
Ctrl+C / Ctrl+X / Ctrl+Vcopy / cut / paste nodes (also into another graph or editor window)
Ctrl+Z / Ctrl+Shift+Zundo / redo (also undoes edits made by AI)
drag a parameter labelscrub the value; B button exposes it to Blender

Edits are saved to the graph file and show up live in Blender and in other editors.
